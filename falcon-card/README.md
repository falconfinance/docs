# Falcon Card

## Introduction to Falcon Card

Falcon Card is a virtual card that allows users to spend USDf for everyday online and offline purchases. It is issued directly through the Falcon Finance app and can be used anywhere Visa is accepted, making it easy to use digital assets as a form of everyday payment.



To learn more about how to apply and use Falcon Card, read more [here](https://docs.falcon.finance/falcon-card/how-to-use-falcon-card).
